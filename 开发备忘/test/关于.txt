FinchPad，旨在成为 Windows、macOS 和 Linux 上更好的默认文本编辑器。主要特点：    • 极致轻量与高性能：基于 Rust 构建，安装包约 5MB，运行内存约 10MB，保持快速启动与低资源占用    • 多标签页编辑：采用现代浏览器式标签页设计，轻松管理多个文档    • 会话恢复：即使遇到软件崩溃、系统重启或意外断电，也能恢复之前的工作状态    • 安全缓存：使用系统级密钥管理与 AES-256-GCM 加密保护本地缓存数据    • 文件冲突处理：智能检测文件变化，帮助处理编辑冲突    • 大文件支持：快速打开和编辑大型文本文件    • 自定义主题：支持个性化编辑环境    • 文本对比：快速查看文件之间的差异    • 跨平台支持：Windows / macOS / Linux基于 Tauri 2、Svelte 5、Rust 和 Monaco Editor 构建。开源协议：MIT License
