FinchPad, designed to be a better default text editor experience across Windows, macOS, and Linux.Key Features:    • Extremely lightweight and high performance: Built with Rust, with an installation size of around 5MB and approximately 10MB of memory usage, delivering fast startup and low resource consumption    • Multi-tab editing: A modern browser-style tab design for managing multiple documents with ease    • Session recovery: Restore your previous work even after crashes, system restarts, or unexpected power outages    • Secure caching: Uses system-level key management and AES-256-GCM encryption to protect local cache data    • File conflict handling: Automatically detects file changes and helps resolve editing conflicts    • Large file support: Quickly open and edit large text files    • Customizable themes: Personalize your editing environment    • Text comparison: Quickly view differences between files    • Cross-platform: Windows / macOS / LinuxBuilt with Tauri 2, Svelte 5, Rust, and Monaco Editor.Open source under the MIT License.
